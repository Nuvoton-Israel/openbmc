Data Flow:
══════════

1. PWM Configuration:
   User → pwm_test.sh → /sys/class/pwm/pwmchip0/pwm0/ → PWM0 Hardware

2. TACH Simulation:
   PWM0 → sysfs → pwm_tach_sim → libgpiod → GPIO03 → TACH Signal

3. Closed Loop Test:
   pwm_test.sh (sweep) → PWM duty cycle changes
                      ↓
   pwm_tach_sim reads duty cycle
                      ↓
   TACH frequency adjusts proportionally
                      ↓
   GPIO03 toggles faster/slower


Frequency Mapping:
═══════════════════

  PWM Duty Cycle          TACH Frequency
  ──────────────          ──────────────
       0%          →           10 Hz
      25%          →          257 Hz
      50%          →          505 Hz
      75%          →          752 Hz
     100%          →         1000 Hz


Example Usage:
═══════════════

Terminal 1:                    Terminal 2:
──────────                     ──────────
# Setup PWM                    # Start simulator
pwm_test.sh setup              systemctl start pwm-tach-sim
                               
# Set 50% duty                 # Monitor output
pwm_test.sh set 50             journalctl -u pwm-tach-sim -f

# Sweep test                   # Observe frequency changes
pwm_test.sh sweep              (TACH frequency varies with duty)
